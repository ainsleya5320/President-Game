# Inauguration introduction

Three original fictional images generated with the built-in image generation tool; these do not depict a particular real president. Exact prompts are preserved in prompts.json.

The native Unreal game presents the images as an 18-second montage with slow pans, zooms and fades, followed by a player-paced welcome briefing. No audio is included.

New presidencies play it automatically. Existing saves keep their progress and do not auto-play it. Press **I** while walking to replay. **Enter**, **Space**, **Escape**, or the visible button skips to the briefing; use Continue to return to the game. The briefing never advances on a timer.

PNG files are loaded at runtime and staged as NonUFS files by the module build rules.
